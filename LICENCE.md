## 🧩 About

**Knight Online overlay** is a curated list of Knight Online open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap overlays, coordinate displays
- **Quality-of-Life Helpers** — inventory sorters, chat filters, macro recorders for study
- **Research Notes** — packet structure analysis, client behavior notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### 🎮 Gameplay Helpers
- Coordinate Viewer — display player position on screen
- Target Info Panel — show basic stats of selected target for study
- Distance Indicator — measure range to objects and entities
- Auto-Loot Notes — documentation on loot collection patterns
- Skill Timer Overlay — track cooldowns for practice

### 🗺️ Map & Navigation
- Minimap Overlay — enlarged map with markers for study
- Waypoint Notes — record and review paths in zones
- Entity Tracker — list nearby NPCs and players for reference
- Loot overlay — highlight item drops in the vicinity (educational)

### 🎨 Interface & QoL
- Custom HUD — rearrange UI elements for clarity
- Chat Filter — highlight keywords in chat for research
- Inventory Sorter — organize items by type
- Macro Recorder — record and playback simple actions for testing

### 🔧 Configuration & Tools
- Config Editor — adjust overlay settings via INI
- Hotkey Manager — assign keys to toggle features
- Safe Mode — conservative defaults to avoid unintended actions

## 🛠️ Troubleshooting

- **Overlay not showing:** Ensure the game is running in windowed or borderless mode. Run the helper as administrator if needed.
- **Hotkey conflicts:** Change `menu_hotkey` in the config file to a different key.
- **Game crashes on launch:** Disable safe mode or check for conflicting overlays (e.g., Steam overlay).
- **Antivirus flags:** Some tools may be flagged due to memory reading; add an exclusion if you trust the source.
- **Process not found:** Verify the process name in Task Manager and update `process_name` accordingly.
